Cavaleiro III — Movimentar

Network Policies

Default Deny · Segmentação · Zero Trust
"Sem Network Policy, cada pod vira um ponto de partida. Movimentação lateral é o superpoder do atacante."
frontend → backend → payments-db
(o frontend nunca deveria tocar o banco)
Rode a partir de: demo/cavaleiro-3-network/  ·  o cluster usa Calico (o kindnet ignora NetworkPolicy)
1

O cenário: frontend, backend e banco

kubectl apply -f app.yaml
kubectl -n c3-network get pods -w

→ Espere os 3 pods em Running (Ctrl+C sai do -w). O frontend é o pod comprometido.

2

O frontend comprometido vai DIRETO no banco

"Esse pod nunca deveria falar com o banco. Mas a rede é plana, então ele fala. Se tudo conversa com tudo, qualquer invasão escala."
kubectl -n c3-network exec frontend -- wget -qO- http://payments-db:8080

→ O frontend recebe o conteúdo sensível do banco — pulando o backend. Movimentação lateral.

3

A defesa: segmentar por camada

"A regra não é bloquear tudo para sempre. É deixar cada camada falar só com a próxima — e nada além."
kubectl apply -f default-deny.yaml
kubectl apply -f allow.yaml

→ default-deny corta tudo; allow libera só frontend→backend e backend→db.

4

O atacante perde o banco — e não volta

"O frontend não tem mais caminho para o banco. Nunca deveria ter tido."
kubectl -n c3-network exec frontend -- wget -qO- -T 5 http://payments-db:8080

✗ Timeout. O frontend está cortado do banco — e continua cortado, não há regra que o devolva.

5

Mas o serviço continua de pé

"Zero Trust não derruba o serviço. Derruba os caminhos que não deviam existir."
kubectl -n c3-network exec backend -- wget -qO- http://payments-db:8080
kubectl -n c3-network exec frontend -- wget -qO- http://backend:8080

✓ O backend continua lendo o banco (legítimo) e o frontend continua falando com o backend (normal). Só o atalho perigoso sumiu.

Camada seguinte (Cavaleiro 4): mesmo o backend não usa senha fixa — ele pega a credencial do banco do Vault, curta e rotacionada. Rede + segredo = defesa em profundidade.

Reset

kubectl delete -f allow.yaml -f default-deny.yaml -f app.yaml --ignore-not-found
