Cavaleiro IV — Roubar Credenciais

Secrets

Vault · External Secrets Operator · Workload Identity
"Base64 nunca foi criptografia. O cluster é temporário. As credenciais sobrevivem."
Rode a partir de: demo/cavaleiro-4-secrets/  ·  é a senha do banco que o backend (Cavaleiro 3) usa
1

A senha do banco, do jeito ingênuo

kubectl apply -f insecure-secret.yaml

→ Um Secret do Kubernetes com a senha do banco — que não é criptografado.

2

"Roubar" a senha é um comando só

"Não está criptografada, está codificada. E é a senha do banco que o backend usa. Quem lê secrets, lê o banco inteiro."
kubectl -n c4-secrets get secret db-credentials -o jsonpath='{.data.password}' | base64 -d; echo

✗ A senha do banco aparece em texto puro. Qualquer um com permissão de leitura vê.

3

A defesa: a senha vai para o cofre (Vault)

"A senha sai do cluster e vai para um cofre, com auditoria e rotação."
kubectl -n vault exec vault-0 -- sh -c \
  'VAULT_ADDR=http://127.0.0.1:8200 VAULT_TOKEN=root vault kv put secret/db password=senha-ROTACIONADA-pelo-vault'

→ A senha agora vive no Vault, não em um manifest.

4

Conecta o cluster ao cofre (External Secrets Operator)

kubectl -n c4-secrets create secret generic vault-token --from-literal=token=root
kubectl apply -f secretstore.yaml
kubectl apply -f externalsecret.yaml

→ O ESO passa a sincronizar a senha do Vault para dentro do cluster.

5

O ESO materializa a senha — sem ela estar no git

"A senha não mora mais no cluster nem no repositório. Mora no cofre, e o backend pega emprestado quando precisa."
kubectl -n c4-secrets get externalsecret
kubectl -n c4-secrets get secret db-credentials-managed -o jsonpath='{.data.password}' | base64 -d; echo

✓ db-credentials-managed existe, com o valor vindo do Vault — que nunca passou por um manifest.

Produção: troque o token estático por Workload Identity, e prefira credenciais dinâmicas (o Vault emite usuário/senha de banco com TTL curto — a senha que vaza expira sozinha).

Reset

kubectl delete -f externalsecret.yaml -f secretstore.yaml -f insecure-secret.yaml --ignore-not-found
kubectl -n c4-secrets delete secret vault-token db-credentials-managed --ignore-not-found
